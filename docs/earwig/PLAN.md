# Earwig: build plan

Earwig is a generic AI audiobook companion, forked from The Crawl (itself a fork of Voice). It drops everything that
was specific to Dungeon Crawler Carl and makes the companion features work for any DRM-free `.m4b` or `.mp3`.

## Product summary

1. **Add a book.** The user picks an audio file. A guided setup screen opens and stays the book's home for setup.
2. **Transcription starts on its own** (cloud speech-to-text, Deepgram). The audio is cut into 20 minute parts on the
   phone and each part is uploaded and transcribed; the setup screen and a notification show progress
   ("Transcribing part 7 of 28"). Finished parts are checkpointed, so a killed app resumes where it left off.
3. **While that runs, Claude researches the book online** (Claude's web search tool): fiction or non-fiction, what it
   is about, key themes, and for fiction whether it has a large cast. The result is a **Book profile**.
4. **From the profile, Claude proposes Extras**: 3-5 idea cards, each tied to one of the extension points below.
   The user taps **Build** or **Skip** on each. A text box lets the user describe their own idea; Claude checks it
   against what the app can actually do and answers "can build" (with the extension point it would use) or "can't,
   because ..." with a nearby alternative.
5. **Baseline features**, as in The Crawl, all answered from the transcript up to the listener's position:
   Snip, Ask (typed or spoken), Recap the last 30 minutes, "What's happening?" (auto-identify), headset button
   shortcuts. Spoken answers use the phone's text-to-speech only.
6. **Look**: a cream, red and black default theme (The Crawl's Book 8 palette). Each book can instead take its
   colors from its cover, or the user can generate a custom cover with Ideogram from a base prompt plus their own
   extra prompt, and regenerate it.
7. **Keys**: Claude, Ideogram and Deepgram API keys are entered in Settings and stored on the device. Nothing is
   hardcoded, so anyone can use the app with their own keys.

## Extension points

Claude can't change the app itself. It builds **Extras** that plug into three fixed places:

| # | Extension point | What Claude can build there |
|---|---|---|
| 1 | **Snip picture** | The style of the picture drawn for each snip: a sketchnote, an infographic, a diagram, a scene illustration. Claude writes the image prompt from the snip and the book's style; Ideogram draws it. |
| 2 | **Extras shelf** (the Notebook's second tab, which replaces Strips) | Interactive companion pages: calculators, explainers, timelines, quizzes, family trees, checklists. Each is a small sandboxed web page that runs inside the app, styled with the book's colors. No limit on how many. |
| 3 | **Scene chips** (replaces X-Ray) | Fiction: character chips for whoever is in the scene, each opening a simple character card in the book's style, written only from what the listener has heard so far. Non-fiction: topic chips that surface while a topic is discussed and unlock the related Extra on the shelf. Built by a batch job over the transcript. |

### The Extras runtime

An Extra is a manifest plus one self-contained HTML file, generated by Claude:

```json
{ "id": "...", "title": "Compound interest calculator", "description": "...",
  "kind": "tool | explainer | quiz | timeline | reference",
  "unlock": { "afterMs": 5400000, "topicId": "compounding" },
  "html": "<!doctype html>..." }
```

It runs in a WebView with JavaScript on, no network (a strict Content-Security-Policy plus blocked requests), no file
access, and one global object, `earwig`, defined before the page's own script runs:

| Call | What it does |
|---|---|
| `earwig.book()` | Title, author, kind (fiction / non-fiction), summary, duration and the listener's position. |
| `earwig.transcript(maxChars)` | The transcript the listener has heard so far, the last `maxChars` characters of it. |
| `earwig.ask(question)` | A promise of one Claude answer, through the same spoiler-safe Ask as the player. |
| `earwig.get(key)` / `earwig.set(key, value)` | Small per-Extra storage, kept on the device and removed with the Extra. |
| `earwig.seek(positionMs)` | Jumps playback to a moment in the whole book and closes the page. |
| `earwig.close()` | Closes the Extra. |

The page gets the book's colors and fonts as CSS variables (`--bg`, `--ink`, `--accent`, `--accent-ink`, `--muted`,
`--font-display`, `--font-body`), so it looks like part of the app. If a page throws while loading, the app shows
**Fix it**, which sends the error back to Claude for a repair pass (also in the page's menu, for pages that
run but don't work as they should).

Why web pages and not native code: Android can't compile or safely load new native code at runtime, and Play policy
forbids downloading executable code. A sandboxed page is the same idea as a Claude artifact, and with the injected
theme it reads as native.

## Models and cost

| Job | Model | Rough cost for a 15 hour book |
|---|---|---|
| Transcription | Deepgram Nova-3 | about $4 |
| Book research | Claude Sonnet 5.5 with web search | a few cents |
| Idea cards, feasibility checks | Claude Sonnet 5.5 | cents |
| Building one Extra | Claude Opus 5.5 | 5-20 cents |
| Scene chip batch (characters or topics) | Claude Haiku 5.5 over the transcript in one-hour windows | 5-20 cents |
| Ask, recap, snip, what's happening | Claude Sonnet 5.5, streamed | under a cent each |
| Snip picture, cover | Ideogram | a few cents each |

Every batch job shows its rough cost before it starts.

## Build steps

Each step is one commit, in this order.

- **Step 0. Fork setup.** New app id `com.ivipul.earwig`, app name Earwig, user-facing "Voice"/"Crawl" strings
  replaced. This plan.
- **Step 1. Remove DCC pieces.** Holo cards and The Deck, comic strips and their story player, the bundled per-book
  covers, fonts and palettes, player cards, Fish Audio voice, System AI persona, Jev/OpenRouter routing, Gemini,
  the comic snip frames. Default theme becomes cream/red/black.
- **Step 2. Keys and clients.** API keys in Settings (`ApiKeys` DataStore). `ClaudeClient` on the official
  Anthropic Java SDK (text, streaming, structured JSON, web search). `IdeogramClient` generalized.
- **Step 3. Add a book and transcribe.** Pick a file, register it, open the setup screen. `TranscriptionWorker`
  (WorkManager, foreground) cuts the audio into parts (`AudioChunker`), sends each to Deepgram, merges the cues into
  the transcript file the co-pilot already reads, and reports progress.
- **Step 4. Research and idea cards.** `BookResearcher` builds the profile, `IdeaGenerator` the cards,
  `FeasibilityChecker` answers the user's own ideas. Setup screen shows all of it.
- **Step 5. Extras runtime.** `ExtraBuilder` (Claude writes the page, the app validates it), `ExtraStore`, the
  WebView host and bridge, the Extras shelf in the Notebook.
- **Step 6. Snip picture.** The snip pipeline draws a picture in the book's chosen style.
- **Step 7. Scene chips.** `SceneIndexer` batch job (characters or topics), chips, character cards, topic unlocks.
- **Step 8. Book look.** Palette from the cover, custom cover generation with an extra prompt, regenerate.
- **Step 9. Polish.** Tests, docs, cleanups.

## Storage

Everything Earwig creates lives in the app's private storage. Transcripts sit under `filesDir/transcripts/`, one
file per audio file, keyed by a hash of its URI (a transcript that came with the audio file, next to it, is used
instead and nothing is sent to Deepgram). Everything else is under `filesDir/books/<book key>/`:

```
setup.json             where the setup is: transcription parts, research, ideas, scene scan
profile.json           the Book profile
ideas.json             idea cards and their state
extras.json            built Extras (the page, title, unlock point, topic, last error)
extra-data/<id>.json   values an Extra saved for itself
scene.json             scene chips: spans, aliases, notes that unlock with the position, linked Extra
look.json              colors source, palette, display face, snip picture style, cover prompt
original-cover         the book's own cover, kept while a generated one is in use
generated-cover-*.png  the last generated cover
```

API keys, transcripts and book folders are excluded from cloud backup.

## Not in this build

- On-device transcription.
- Sharing Extras between users.
- Android Auto changes beyond renaming.

## Ideas added while building

- Transcription in 20 minute parts, three at a time, checkpointed so a stopped run resumes, and the transcript is
  rewritten after every part, so Ask, Recap and Snip work on the parts already done.
- A cost estimate (Deepgram, per minute of audio) on the setup screen before anything starts.
- Audio files that come with a transcript next to them skip Deepgram.
- Research also picks a display face for chapter names that suits the book; the setup screen can change it.
- Scene cards keep their notes spoiler-safe: each note shows only once playback reaches the point it describes.
- Extras unlock by position or by their topic chip, with a "New Extra on your shelf" toast on the player.
- Extras can ask Claude and read the transcript heard so far at runtime, so a quiz or explainer stays current.
- Fix it repairs a broken Extra with Claude; Delete removes it with its saved values.
- The book's original cover is kept and comes back when the look is switched away from a generated cover.
- Library and settings sit on white, so the cream book cards stand out.
- Book setup is reachable from the player's menu and the library's long-press sheet, not only when adding a book.

## Assumptions made without asking

- App name **Earwig**, app id `com.ivipul.earwig`, so it installs next to The Crawl.
- Deepgram for transcription (needs a Deepgram key, a free trial covers several books).
- Opus 5.5 for building Extras (quality matters most there), Sonnet 5.5 for conversation, Haiku 5.5 for batch scans.
- The GitHub repo `ivipul/Earwig` couldn't be created from the cloud session, so the work is on branch
  `claude/project-thread-v8xdua` of `ivipul/Voice`. To make the standalone repo, run on the Mac:
  `gh repo create ivipul/Earwig --private && git push git@github.com:ivipul/Earwig.git claude/project-thread-v8xdua:main`.
